AR SOLUTIONS DJANGO WEBSITE V1

Included:
- Existing premium V4.1 interface
- Django admin panel
- Dynamic products
- Dynamic pricing plans
- Demo requests saved to SQLite database
- Contact enquiries saved to SQLite database
- Enquiry status management
- Email notification settings
- WhatsApp button
- Admin branding
- Starter data command

First run:
1. Extract the ZIP.
2. Double-click INSTALL_AND_RUN.bat
3. Create the admin username and password when asked.
4. Website: http://127.0.0.1:8000/
5. Admin: http://127.0.0.1:8000/admin/

Later daily use:
- Double-click RUN_WEBSITE.bat

Important:
- Replace the placeholder email, phone and WhatsApp details.
- Configure real SMTP email in environment variables before launch.
- DEBUG must be False for production.
- A domain, hosting, SSL and production server are still required before public launch.
